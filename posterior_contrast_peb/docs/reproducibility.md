# Reproducibility map

All released numerical analyses use MATLAB R2023b and SPM12 revision 7771
where SPM functions are required.

## Data S1

`results/data_s1/` contains the 500-replication posterior-anchored
variance-allocation grid and covariance-scale sensitivity analysis. The public
runner is `simulations/posterior_anchored/run_empirical_anchor.py`.
The released group-effect coverage intervals use Wilson intervals with the
pooled coefficient-level denominator recorded by the simulation design.

## Data S2

`results/data_s2/` contains the native-SPM structural-information grid and the
50-replication hyperparameter-uncertainty calibration analysis. The native
runner is
`simulations/spm12/run_native_target_precision_compression_simulation.m`.
Coverage intervals in both released Data S2 summary tables are finite-sample
exact intervals. Scalar targets use central Clopper-Pearson binomial
inversion. Two-dimensional targets retain the paired marginal indicators from
each replication and use central exact trinomial test inversion computed
numerically with a 4,097-point nuisance grid and root tolerance `1e-10`.
Outcome tuples are `(not covered, covered)` for scalar targets and
`(neither covered, one covered, both covered)` for paired targets. The released
outcome-count and method columns are reproduced by
`simulations/spm12/compute_exact_coverage_intervals.py`.

## Data S3

`results/data_s3/` contains independent-sample predictive comparisons,
subject-level nested cross-validation results for FingerData, full-data
stacking weights, and final Gaussian-mixture summaries. The combination
algorithms are implemented in `simulations/prediction/`.

The four candidate specifications are `source_single`, `source_all`,
`target_direct`, and `rotated_fitted`. The reported decision rules are hard
inner selection, equal averaging, regularised stacking, and pseudo-BMA+.

## Data S4

`results/data_s4/` contains 20 empirical dataset-target-specification audits,
the generalized-eigenvalue threshold check, target-covariance posterior
summaries, the exact target matrices used for FacesData, GeometryData, and
FingerData, complete source-parameter orderings, and the realised fitted
precision components in sparse long format. The component export records both
the base matrices and their fitted `exp(Eh)`-weighted values. The residual
baseline precision term and module-level target projections are also included
for independent reconstruction of source, rotated, and direct fitted target
covariances. Module-level software and input provenance is reported in
`results/data_s4/computational_provenance.md`.

## Secondary validation

`results/secondary_validation/` contains the matched target-family check, the
R=4 target-family analysis, and the source-family versus target-family BMR/BMS
comparison. These results are generated by the scripts under
`simulations/spm12/`.

## Integrity tests

`tests/test_release_results.py` checks cell counts, replication counts,
candidate labels, nested-fold completeness, effective candidate counts, and
the empirical generalized-information spectral gap against the frozen tables.
It also checks the exact coverage-interval metadata and the completeness of
the empirical parameter-ordering, precision-component, baseline-precision,
and fitted-projection exports, including reconstruction of all 20 reported
target random-effects covariance matrices.
