# Reproducibility map

All released numerical analyses use MATLAB R2023b and SPM12 revision 7771
where SPM functions are required.

## Data S1

`results/data_s1/` contains the 500-replication posterior-anchored
variance-allocation grid and covariance-scale sensitivity analysis. The public
runner is `simulations/posterior_anchored/run_empirical_anchor.py`.

## Data S2

`results/data_s2/` contains the native-SPM structural-information grid and the
50-replication hyperparameter-uncertainty calibration analysis. The native
runner is
`simulations/spm12/run_native_target_precision_compression_simulation.m`.

## Data S3

`results/data_s3/` contains independent-sample predictive comparisons,
subject-level nested cross-validation results for FingerData, full-data
stacking weights, and final Gaussian-mixture summaries. The combination
algorithms are implemented in `simulations/prediction/`.

The four candidate specifications are `source_single`, `source_all`,
`target_direct`, and `rotated_fitted`. The reported decision rules are hard
inner selection, equal averaging, regularised stacking, and pseudo-BMA+.

## Data S4

`results/data_s4/` contains 20 empirical dataset-target-specification audits,
the generalized-eigenvalue threshold check, target-covariance posterior
summaries, and the exact target matrices used for FacesData, GeometryData, and
FingerData.

## Secondary validation

`results/secondary_validation/` contains the matched target-family check, the
R=4 target-family analysis, and the source-family versus target-family BMR/BMS
comparison. These results are generated by the scripts under
`simulations/spm12/`.

## Integrity tests

`tests/test_release_results.py` checks cell counts, replication counts,
candidate labels, nested-fold completeness, effective candidate counts, and
the empirical generalized-information spectral gap against the frozen tables.
